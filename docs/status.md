# 交付状态：已完成 / 未完成 / 已知问题

> 作业第 6 节要求 README 里说明这三项。README 只放"怎么跑、怎么验"，实现状态和取舍统一记在这里。

## 已完成

**手机端**：真机运行；检测水平平面并在画面上显示网格；点击平面在命中位置放置标记，标记挂在锚点下，相机移动后不随之滑动；填写标题、描述、优先级后提交；成功与失败都有明确提示；表单展开时点击不会再放标记。另有两处门控：跟踪不可靠（Limited / None）时禁止放置与提交；锁屏或切后台回来时清空已放置标记并提示重新放置——ARCore 恢复后会重新定位，旧坐标不再可信。

**管理端**：列表与详情；展示标题、描述、优先级、状态与时间；三态修改（open / in_progress / resolved），界面以服务端响应为准，不做乐观更新；后端不可用时显示错误说明与重试入口，不白屏；内置请求日志面板，可直接核验每次往返。

**后端**：五个端点（健康检查、创建、列表、改状态、统一兜底）；唯一 id（insp_ + ULID）与默认 open；参数错误返回 400 与具体错误码；数据落 SQLite，进程重启后仍在。

**工程**：契约冻结在 docs/api.md；37 项冒烟脚本；24 个 Go 测试（model 单测 + HTTP 层契约测试）；统一错误出口；请求 id 贯穿两端日志；panic 兜底；优雅退出；配置按环境分档；三端字段名逐字对齐。

## 未完成 / 已知问题

分三类：**功能缺口**（v1 明确不做）、**已知缺陷**（做了但不够好）、**使用注意**（不是缺陷，但会踩坑）。

| 类别 | 条目 | 现状 | 后续 |
|---|---|---|---|
| 功能缺口 | 状态变更历史（BR-08） | 只存当前状态，没有变更流水表 | v1 不做 |
| 功能缺口 | 处理人与验收证据 | 无字段、无界面 | v1 不做 |
| 功能缺口 | 现场截图上传 | 契约留了端点（`docs/api.md` 第 9 节），未实现 | v1 不做 |
| 功能缺口 | 鉴权 / 分页 / 作废状态 / 离线队列 | 全部未做 | v1 不做 |
| 已知缺陷 | 垂直面检测差 | ARCore 的平面检测只凑几何、不认语义。地面（含桌面）能勉强覆盖，垂直面常常一块块"插进实体墙面里" | SDK 层面的限制，没有做补偿 |
| 已知缺陷 | 跨会话 / 跨设备找回位置 | 未实现。需要 4×4 变换矩阵对齐两个会话的坐标系 | 加分项，v1 明确不做 |
| 已知缺陷 | 手机端界面用 IMGUI | 很简陋。选它是为了确保 Android 上中文能正常显示（无需处理字体回退） | 优先保证"能填、能提交、有回馈" |
| 使用注意 | `adb reverse` 会掉 | USB 断开重连、adb 服务重启、重新 install 之后失效，症状是 App 报"连不上后端" | 重跑一条命令即可，代码不用动 |
| 使用注意 | `adb` 不在 PATH | 需先用 platform-tools 目录下的全路径，或把该目录加进 PATH | 见「快速开始 · 手机端」 |
| 使用注意 | 构建产物不进仓库 | `ar-client/Builds/app.apk` 在 `.gitignore` 里 | 按「快速开始 · 手机端」自行构建 |
