## 三、三条判断，供评委核对

1. **跟踪不可靠时不放置。** ARCore 位姿靠特征点与惯性融合，特征点不足时位姿在漂，但射线仍然打得到平面、方块也仍然出现在手指下——"看起来完美"，等跟踪恢复才暴露坐标是错的。判定口径写在 `04-断言与核验.md` 链路一。
2. **锁屏回来不信旧坐标。** 实测每次漂移超过 30cm。坐标系已经换了，硬撑只会给出看起来对、其实错的位置，所以恢复后清空标记并明确提示，而不是假装还在原地。
3. **范围只收敛不扩张。** 12-Factor 读了 4 条、日志那一节读完主动放弃，把时间投到能变成分数的业务流程检查上；理由记录在 `docs/process/06-提示词脉络.md`。
