## 四个转折（脉络在转折里，不在段里）

1. 搭通了闭环，但下一个问题不是技术问题：**评审怎么拿到它？** → 转去做交付化。
2. 交付齐了，却发现自己说不清一件事：**凭什么说它「可靠」？** → 去借外部的尺子。
3. 概念读不完 → 把问题从「可靠是什么」换成 **「我怎么验它」**。
4. 方法够用了，剩下两天半只够一件事：**按范围验收**。

1. **抽象必须落回可判真假**——每个概念都追到"看得见的现象 / 能跑的命令"。
2. **每次学习都留文档**——方法记录、断言清单、AI_LOG，不留口头结论。
3. **范围只收敛不扩张**——12 条 → 4 条 → 1 条 → 作业原文 19 条。
